## Independent design challenges and compliance
- Do not allow a long-running Pipe HTTP stream to become the only source of task identity or truth. Supervisor must retain status and task ID across WebUI disconnection and server restart.
- **Cancellation:** UI Stop may terminate the UI response while work remains in the separate process. The task must be addressable later, with explicit state readback and no new specialist/tool step after accepted cancel. Define cancel-before-commit / cancel-after-terminal race outcomes and idempotent cancellation request semantics before G-A.
- **Checkpoint saver:** In-memory checkpointers do not establish release-required durability. A backed saver and explicit recovery semantics are mandatory; pin its concrete package/version only after source evidence and offline dependency review.
- **Packaging:** pinned Open WebUI `pyproject.toml` requires Python >=3.11 and <3.13. Historical project lock script points at a Python 3.12 installation path, but actual target runtime and dependency closure remain unverified. Historical script still resolves **LiteLLM** and must be reconciled in an approved implementation phase; do not silently treat it as current architecture.
- **License gate:** [Open WebUI v0.12.5 LICENSE](https://github.com/open-webui/open-webui/blob/f7ac7ee10962ddec0017f5c29b6740d9b9c5faca/LICENSE) requires redistribution notices and sets branding restrictions, with an exception for deployments/distributions at or under 50 end users in a rolling 30-day period. R1 should preserve upstream branding and notices rather than assume permissive rebranding. [LangGraph 1.2.19 license](https://github.com/langchain-ai/langgraph/blob/5bd231cbfd913e05ebc662f519eb9a655bc766df/libs/langgraph/LICENSE) is MIT. License review for all transitive dependencies, binaries and models still required.
