# RP-03 — 19 source-first interface boundary dispositions (candidate)

**2026-11-16. NOT G-A APPROVED.** Independently assessed using exact original `19_INTERFACE_DRAFTS_FOR_CHALLENGE.csv`, v3 19-interface reviewer records, separate 2026-11-15 interface assessments, and *later* owner-approved R1/R2/R3 strategy. Historical original interface IDs, purposes, candidate releases, and source records are unchanged. These are proposed functional contracts, not frozen API field schemas or verified Bifrost/Open WebUI behavior.

**Required distinction:** producer constructs and truthfully reports data; consumer validates and applies its own responsibility; neither may silently assume another component has authorized a request. Do not mandate unnecessary adapters, brokers, registries, or threat models in a single-operator local release. Exact wire-format, status enums, retry/timeout values and version compatibility require offline pinned-client/API evidence and then authorized G-A review.

## Release 1 interfaces

| Original ID | Producer → consumer / owned information | Candidate invariant and rejection/failure witness |
| --- | --- | --- |
| IF-01 | Open WebUI **direct-model path** → Bifrost gateway; UI owns choice and conversation identity; gateway owns admission and routing | Direct chat and model listing work without LangGraph. Preserve selected/dispatch/resolved model identity; distinguish ordinary response, SSE and error. Missing/invalid gateway credential or disallowed model rejects before Ollama. An uncontrolled retry must not fabricate success |
| IF-02 | Open WebUI **delegated mode** → independently executable LangGraph supervisor; WebUI owns conversation/history, supervisor allocates task ID and status | A user-initiated request returns accepted task ID, visible state and final or typed failure; cancellation is addressable by task ID; bounded conversation excerpt only. **Do not mandate both an Open WebUI Pipe adapter and an HTTP adapter** until supported deployment path is proven |
| IF-03 | LangGraph specialist role → Bifrost gateway → local Ollama; supervisor owns role/task identity and context bounds | Each role's model request reaches gateway, not direct Ollama; gateway validates model/key. Correlate task/role/request and selected/resolved model; failures recorded as failures, not verified specialist output. Neither role text nor UI may supply a trusted gateway policy verdict |
| IF-05 | Open WebUI → its authoritative history store; UI owns user-facing chat persistence | Ordered conversation can be reopened after UI restart. LangGraph stores only task/checkpoint/provenance, not a second authoritative chat archive. Failed save must not report durable history |
| IF-06 | LangGraph → its own checkpoint store; supervisor owns task ID, state and recovery rules | Acknowledged checkpoint survives controlled service restart; cancellation/failed/partial terminal status is truthful. If checkpoint unavailable/corrupt, report recovery error; don't recreate a fake successful task. Define atomicity only to extent required by actual local store |
| IF-UI | Single operator ↔ local Open WebUI session; WebUI owns presentation and mode selection | Distinct direct/delegated modes usable, task status visible, history available; anonymous management disallowed. Local-only is administration perimeter, not general host network air-gap |
| IF-LOCAL | Bifrost OSS → selected local Ollama instance; gateway owns permitted backend route | Approved local model completes/streams; local dependency failure typed; no hosted fallback. Host and port belong to deploy-time configuration, not a hard-coded universal product requirement |
| IF-LOG | UI/gateway/supervisor/tool adapters → sanitized local operational record | Correlatable safe event metadata with trace IDs and measured/UNKNOWN counters; no raw prompts, completions, secrets, or external application telemetry. 30-day retention **only for sanitized operational metadata**. Examine real journal/container/diagnostic sinks, not just one adapter |
| IF-TOOL | LangGraph tool-request admission → approved nondestructive local tool adapter | Structured inputs validated, active task grant checked *before* tool call, decision recorded without secret data. Unapproved action produces denied result and zero adapter execution. Do not build unattended consequential approval engine in R1 |
| IF-BACKUP | Authorized operator backup/restore operation → Open WebUI history, LangGraph checkpoints, Bifrost config | Offline locally stored access-controlled complete artifact; restore independent on clean target with genuine readback; reject invalid backup before overwriting live data. **No mandatory encryption**; allow future optional envelope/version seam without implementing key hierarchy now |
| IF-OPS | Host service management → configured R1 services and application-data mount | Required mount present before writers start; supported startup/restart order, accurate health and controlled recovery. A missing mount blocks writes into underlying directory. systemd/Docker particulars are verified deployment facts, not immutable architecture |
| IF-PACK | Project-owned `.deb` install/upgrade/remove + complete offline dependency transport archive → target Bodhi Linux 7 AMD64 | Install and run *without dependency downloads* from transport archive; verify exact versions, ABI, checksums, notices and redistribution rights. Invalid artifact fails; rollback preserves usable user data. **Do not claim .deb remains unapproved**; no general multi-distribution installer required |
| IF-MGMT | Authenticated local single operator → Bifrost management/configuration API | Only authorized local management reads/writes and key lifecycle work; anonymous or remote unauthorized attempt fails without changing config. Provider-credential management for hosted services is R2 scope |
| IF-CRED | Local credential custodian → Bifrost/UI/LangGraph as required | Issue only a permitted local credential to its required consumer; never insert keys in chat history or diagnostics. Define separate future external API secret-ownership boundary; do not implement R2 vault or credentials now |
| IF-POLICY | R1 request/tool admission → permitted *local* operation | R1 enforce Ollama-only inference and bounded task tool grant; deny unauthorized local tool/model requests. Mark a future **R2 insertion point** for request-specific provider/model/field projection and paid-call control; do not implement hosted policy machinery in R1 |

## Verification boundaries and open technical predicates

1. **IF-01 and IF-03** must share the approved Bifrost boundary while WebUI history and LangGraph checkpoint ownership remain independent (**AC-01**). Test both routes against local Ollama. The R1 gateway remains Bifrost OSS, not historical LiteLLM.
2. **IF-01/03/LOCAL** must make selected, dispatched and resolved provider/model identity observable, without requiring implemented external provider adapters (**AC-02**).
3. **IF-CRED/MGMT** must support the later separation of external-provider secrets from UI history and local keys, at design level only (**AC-03**).
4. **IF-POLICY/LOG/BUDGET** must expose a plausible R2 consent/field-projection/spend insertion point without assigning chat or checkpoint ownership to policy infrastructure (**AC-04**).
5. **IF-02:** select one actual supported, maintainable Open WebUI delegated integration path using pinned-version documentation/offline behavior. Do not canonize an invented two-adapter dependency.
6. **IF-BACKUP/PACK/OPS:** verify on designated supported Bodhi Linux 7 AMD64 target, in an isolated first article, with .deb + complete offline archive and independent three-owner restore; no blanket outbound-deny requirement.
7. **Missing evidence / G1 hold:** no current Bifrost SSE, model-list, management error, restart/cancellation or deployed service verification was performed. Do not label these **TESTED**, **INDEPENDENTLY VERIFIED**, **OWNER ACCEPTED** or frozen contracts.

**Next required authority:** after exact contract fields, independently justified failure semantics and test oracles have been reconciled against the pinned versions and governing approved requirements, submit an explicit G-A owner decision. Until then, all 19 are **CANDIDATE / UNFROZEN**. R2/R3 interfaces are recorded for extensibility but not prerequisites for R1 implementation.
