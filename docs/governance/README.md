# Cross-project engineering governance

These documents are written for reuse across software projects. When adopting one, record its version and a commit-pinned GitHub link in the project's governing references.

The v1.1 draft clarifies delegated authority and technical permissions, installer and runtime privileges, private-use evidence and redistribution, repository review and release states, durable source references, operational witness boundaries, and the role of alignment ratings in conformance review. Section numbering, source attribution and the original text outside those additions are preserved.
